Máy mới cài lại Windows 11 không chạy được do chính sách bảo mật (ExecutionPolicy)?

Windows 11 mặc định chặn chạy script ngoài (`running scripts is disabled on this system`). Mở PowerShell chạy dòng này một lần duy nhất để cho phép:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force

Quy trình sử dụng trong 3 bước

BƯỚC 01 Mở PowerShell

Nhấn phím Windows + X rồi chọn Terminal / PowerShell (Admin).

BƯỚC 02 Dán dòng lệnh

Nhấn chuột phải hoặc Ctrl + V dán lệnh irm ... | iex rồi nhấn Enter.

BƯỚC 03 Xem báo cáo HTML

Script quét 10s và tự động mở file BootReport.html độc lập ngay trên Desktop.

Lệnh online tải trực tiếp mã nguồn mới nhất từ GitHub và thực thi trong bộ nhớ, không để lại file rác:

PS>irm https://raw.githubusercontent.com/nguyenquocanhz/BootReport-Health/main/BootReport.ps1 | iex

Dành cho máy không có kết nối mạng hoặc môi trường nội bộ hạn chế:

1. Tải script: BootReport.ps1 (File gốc) hoặc BootReport.zip.

2. Chạy với cờ Bypass trực tiếp:

PS>powershell -ExecutionPolicy Bypass -File .\BootReport.ps1

Nhà mạng chặn GitHub (ISP DNS Block)?

Nếu nhà mạng chặn truy cập raw.githubusercontent.com, chạy lệnh này để bypass qua Cloudflare DoH (1.1.1.1):

iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://raw.githubusercontent.com/nguyenquocanhz/BootReport-Health/main/BootReport.ps1 | Out-String)

Chi tiết các chỉ số phần cứng

Thời gian Boot Windows Event ID 100

Truy vấn Microsoft-Windows-Diagnostics-Performance để bóc tách thời gian BIOS POST, Kernel Init, Driver Boot và phát hiện ứng dụng làm chậm (ID 101-109).

MainPathBootTime BootKernelPost UserLogonWait
Sức khỏe Pin & Chu kỳ CIM / PowerCfg

Trích xuất dung lượng thiết kế, dung lượng sạc tối đa thực tế và số chu kỳ sạc (cycle count). Tính toán % hao mòn tế bào pin và cảnh báo bảo dưỡng.

DesignCapacity FullChargeCap CycleCount
Sức khỏe SSD & NVMe MSFT_PhysicalDisk

Đọc telemetry chip nhớ SMART: tỷ lệ hao mòn ô nhớ (wear percentage), nhiệt độ vận hành ổ đĩa, lỗi phân vùng NTFS và cảnh báo suy giảm tốc độ.

WearPercentage Temperature NTFS Event 55
Sập nguồn & BSOD Kernel-Power 41

Rà soát System Event Log trong 30-60 ngày: phát hiện mất nguồn đột ngột, lỗi vi xử lý bus PCIe (WHEA) và lỗi màn hình xanh với mã dừng Hex.

Kernel-Power 41 BugCheck 1001 WHEA-Logger
