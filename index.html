Windows Boot & System Health Report (BootReport)

An open-source Windows hardware and boot diagnostic tool featuring Boot Performance breakdown, Battery Health, SSD/NVMe SMART, and System Crash analysis, along with advanced troubleshooting.

Launch Methods

  • Method 1: PowerShell (Recommended)
  • Method 2: Traditional (Offline)

This method is the most convenient and works on Windows 8.1, 10, and 11.

  1. Click the Start Menu, type PowerShell, and open it.
  2. Copy and paste the code below and press Enter.
PowerShell (Administrator recommended) One-line launcher
PS>irm https://get.bootreport.dev | iex
  1. When prompted by UAC, click Yes to grant Administrator permission to collect hardware event logs.
  2. The script will collect all diagnostic metrics and automatically launch your comprehensive BootReport.html on your Desktop!

Use this method if you prefer downloading a file or cannot use the PowerShell online method.

  1. Download the script:
    • BootReport.ps1 (Direct PowerShell script)
    • BootReport.zip (Full package archive)
  2. Right-click the Start Menu > Select Windows Terminal (Admin) or PowerShell (Run as Administrator).
  3. Run the command:
    powershell -ExecutionPolicy Bypass -File .\BootReport.ps1
  4. Optional arguments:
    • -Days 30: Scan last 30 days instead of default 60.
    • -Out "D:\Report.html": Save to custom path instead of Desktop.
    • -Lang vi hoặc -Lang en: Choose language explicitly.
    • -NoOpen: Generate file quietly without opening browser.
Having trouble? (Blocked by ISP or Old Windows)

If the command is blocked:
Some ISPs block newly registered domains. Use this command to bypass DNS blocks (Windows 10/11 only):

iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.bootreport.dev | Out-String)

If you receive a TLS/SSL Error (Older Windows):
If you are on an old build of Windows 8.1 or 10, run this command before the main command:

[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12

Bypass ExecutionPolicy restriction:
If PowerShell restricts running unsigned scripts on your machine:

powershell -ExecutionPolicy Bypass -Command "irm https://get.bootreport.dev | iex"
tip

The generated HTML report is completely standalone with embedded CSS and offline charts. You can share the file directly with tech support or keep it to track battery health over time.

note

The irm command in PowerShell downloads a script from a specified URL, and the iex command executes it. BootReport uses native Windows Diagnostics (WMI, CIM, and Event Logs). It does NOT install background services or modify system files.

Diagnostic Modules & Capabilities

BootReport queries Windows subsystem telemetry and hardware management counters directly to diagnose performance bottlenecks and hardware wear without third-party services.

Boot Time & Startup Degradation

Event ID 100-109

Queries Microsoft-Windows-Diagnostics-Performance/Operational to record exact boot timeline phases down to milliseconds:

MainPathBootTime BootKernelPostTime BootDriversInitTime UserLogonWaitTime

Detects startup degradation caused by sluggish applications (Event ID 101), driver delays (Event ID 102), and service stalls (Event ID 103). Flags reboots exceeding the 30-second SSD threshold.

Battery Wear & Cycle Count

WMI / PowerCfg

Extracts internal battery controller telemetry via native CIM and Powercfg records:

Design Capacity (mWh) Full Charge Capacity Cycle Count Wear Percentage

Measures permanent cell degradation: Wear = (1 - FullCharge / Design) * 100%. Triggers a maintenance warning when wear exceeds 25% or charge cycles exceed 500 loops.

SSD & NVMe SMART Health

MSFT_PhysicalDisk

Queries Storage Reliability Counters directly from the NVMe/SATA controller:

Operational Status Wear Percentage Drive Temperature NTFS Event 55

Monitors remaining flash endurance, operational heat (throttling threshold > 55°C), read/write error counters, and inspects the System log for NTFS block corruption warnings.

Crash & Sudden Power Loss Tracking

Kernel-Power 41 / BSOD

Scans the Windows System Event Log across the past 30 to 60 days:

Kernel-Power 41 (Reboot) BugCheck 1001 (BSOD) WHEA-Logger (Hardware) MiniDump Verification

Catches unexpected power failures, PSU brownouts, WHEA CPU/PCIe bus exceptions, and blue-screen crashes with exact timestamps and hex stop codes.
